ELEMENTOR WHATSAPP REDIRECT

1. Upload this ZIP via WordPress > Plugins > Add New Plugin > Upload Plugin.
2. Activate the plugin.
3. An admin notice will ask you to add your WhatsApp number.
4. Click the link in the notice, enter the full international number with country code (digits only), and save.
5. The notice disappears once a number is saved.

Settings are also available at Settings > Elementor WhatsApp.

The plugin works with all forms using Elementor's .elementor-form class. It collects entered field values automatically and opens WhatsApp with a pre-filled inquiry. Visitors still need to press Send in WhatsApp. Hidden/system fields, file inputs, submit controls, and reCAPTCHA response fields are ignored.
