ELEMENTOR & WPFORMS WHATSAPP REDIRECT

1. Upload this plugin ZIP via WordPress Admin > Plugins > Add New Plugin > Upload Plugin.
2. Activate the plugin.
3. An admin notice will ask you to add your WhatsApp number.
4. Click the link in the notice (or go to Settings > WhatsApp Redirect), enter the full international number with country code (digits only), and save.
5. The notice disappears once a number is saved and remains hidden until removed.

Settings are available at:
Settings > WhatsApp Redirect

Supported Form Builders:
- Elementor Forms (automatically detects .elementor-form)
- WPForms (automatically detects .wpforms-form)

Features:
- Automatically captures field labels and entered values.
- Supports text, email, phone, number, dropdowns, checkboxes, radio buttons, and message/textarea fields.
- Formats checkbox groups and radio selections cleanly.
- Ignores hidden fields, system tokens, submit buttons, honeypots, and CAPTCHA/Turnstile response fields.
- Checks form validation before triggering redirect.
- Uses a single configurable WhatsApp number for all forms across your website.
- Opens WhatsApp (App on mobile, Web on desktop) with a pre-filled, formatted inquiry message.
